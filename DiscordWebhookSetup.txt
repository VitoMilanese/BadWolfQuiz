DISCORD QUESTION WEBHOOK SETUP
==============================

Do not save the real webhook URL in this file or commit it to Git.
The webhook URL contains a secret token that allows messages to be sent
to the configured Discord channel.


OPTION 1: Save the webhook for the current Windows user
-------------------------------------------------------

Run this command in PowerShell after replacing <Discord webhook URL>:

[Environment]::SetEnvironmentVariable(
    "Discord__QuestionWebhookUrl",
    "<Discord webhook URL>",
    "User"
)

Restart Visual Studio after running the command. Visual Studio will then
inherit the saved environment variable automatically.


OPTION 2: Set the webhook only for the current PowerShell session
-----------------------------------------------------------------

Open PowerShell in the folder containing BadWolfQuiz.sln and run:

$env:Discord__QuestionWebhookUrl = "<Discord webhook URL>"
dotnet run --project .\src\BadWolfQuiz.Web

This value is available only in that PowerShell window and disappears
when the window is closed.


REMOVE THE SAVED USER VARIABLE
------------------------------

[Environment]::SetEnvironmentVariable(
    "Discord__QuestionWebhookUrl",
    $null,
    "User"
)
